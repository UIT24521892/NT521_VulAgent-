# Yêu cầu đề — đồ án cuối kỳ VulAgent (nguồn chuẩn)

Chép nguyên văn từ ảnh bảng tiêu chí và danh sách đề do người dùng cung cấp ngày 2026-11-24. Khi tài liệu khác (kể cả [references/prompt_nhom_3.md](references/prompt_nhom_3.md)) mâu thuẫn với file này, theo file này.

## Đề được giao

| Mã | Bài báo | Link | Chủ đề |
|---|---|---|---|
| CK19 | VulAgent: A Hypothesis Validation-Based Multi-Agent System for Software Vulnerability Detection | https://arxiv.org/pdf/2509.11523 | Code vulnerability detection |

Ghi chú: đề trỏ bản **arXiv**; bản ACL 2026 (Findings) là bản xuất bản sau và là bản dẫn repo `HotFrom/VulAgent`. Khi trình bày số liệu, nêu rõ số lấy từ bản nào (xem [docs/source_audit.md §7.5](docs/source_audit.md)).
